# Seed fixtures

[Home](../../README.md) › [Datasets](../README.md) › Seeds

Synthetic source material that `benchmarks.generate_dataset` expands into benchmark sessions. `chatbot.jsonl` holds records with questions and answers for three-turn conversations. `agentic.jsonl` holds recorded tool-call episodes (`read_file`, `run_tests`). Replace or extend them with redacted production traces in the same shape for customer-specific benchmarks.
