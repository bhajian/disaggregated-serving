# DeepSeek V4 Pro — manifests as measured

[Home](../../../../../../README.md) › [Lab](../README.md) › As measured

These are the exact manifests used for the recorded runs, including their original
namespace (`deepseek-v4-pro`) and their node placeholders. They are a historical
record: do not edit them. Deploy through the [lab variants](../README.md), which
compose these folders into the profile's own namespace.

`records/` holds the `deployment*.json` run records copied into the benchmark
client and the original top-level kustomization.
